# Projeto: Automação de Mensagens (Supabase + Z-API)

Projeto desenvolvido para automação de mensagens personalizadas no WhatsApp, integrando um banco de dados Supabase com a API da Z-API.

# Funcionalidade
O script busca até 3 contatos cadastrados no Supabase e envia a mensagem personalizada: *"Olá, [nome] tudo bem com você?"* via Z-API.

# Tecnologias
- Python 3
- Supabase (PostgreSQL)
- Z-API
- python-dotenv

# Setup do Ambiente
1. Clone o repositório e acesse a pasta.
2. Instale as dependências:
   ```bash
   pip install -r requisitos.txt

# Crie um arquivo .env na raiz do projeto com suas credenciais.
    SUPABASE_URL=sua_url
    SUPABASE_KEY=sua_anon_key
    ZAPI_URL=sua_url_da_api

# Banco de Dados
    Crie a tabela de contatos como abaixo:

    create table contatos (
    id bigint generated by default as identity primary key,
    nome text not null,
    telefone text not null
    );

    Após isso, insira os dados para teste, como no exemplo abaixo:
    
    insert into contatos (nome, telefone)
    values ('Heraldo', '5512981645537');

    
    RLS deve estar ativado e deve ter uma policy permitindo o SELECT de ler os dados.

# Executar
    execute o comando no terminal:
    python main.py
